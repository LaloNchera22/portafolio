What we do

The wagering layer for competitive games.

Runinback lets players stake a real, skill-based match, secures the pot, and pays the winner automatically — all through one clean API you drop into your game.

Why we do it

The best matches deserve real stakes.

We grew up on ranked ladders and money matches settled on a handshake. Great games should carry real stakes — without the scams, the middlemen, or the house skimming the pot.

How we do it

No middlemen. No trust required.

The pot lives in an audited on-chain program neither side can touch. Your server reports the result, an oracle verifies it, and the winner is paid in about a second.

The engine

Four primitives. One trustless loop.

Every Runinback match runs the same verifiable path — from pairing players to paying the winner — without you touching a single wallet.

Matchmaking

Pair players, connect wallets, agree the stake.

Drop in a challenge overlay that connects both players' wallets and locks the wager terms before the first frame renders.

  • Wallet connect for Solana & embedded custodial accounts
  • Configurable stake, currency and match rules
  • Anti-collusion checks baked into pairing

Smart Escrow

Funds locked on-chain the moment the match starts.

The pot lives in an audited program, not your treasury. Neither player — nor Runinback — can move it until the result is verified.

  • Non-custodial: you never hold player funds
  • Transparent, on-chain proof of the locked pot
  • Automatic refund path if a match is voided
Explore escrow →
Settlement

The oracle verifies the winner and pays out instantly.

Report the result from your game server; the Runinback oracle validates it and releases the pot to the winner in about a second.

  • Signed result submission from your backend
  • Dispute window with cryptographic evidence
  • Sub-second payout once verified

Developer experience

Plug & play escrow in under 10 lines.

Monetize competition in your game without becoming a payments company. Install the SDK, create a match, settle the result. That's it.

Create your account → Read the docs
match.ts 
import { Runinback } from '@runinback/sdk';

const match = await Runinback.createMatch({
  players: ['player1_wallet', 'player2_wallet'],
  wager: { amount: 1, currency: 'SOL' }
});

await match.start();
// …play the game, then report the result
await match.settle({ winner: 'player1_wallet' });
