Quickstart

From zero to your first API call in three steps.

01 · Key

Issue a test key

Create an account, open the console, go to Dev › API keys and issue a test key. You'll see it in full once; store it as a server secret, never in a browser or app bundle.

.env
RIB_KEY=rib_test_…
RIB_API=https://<project>.supabase.co\
/functions/v1/api
02 · Call

Check your key

Every request sends the key as a bearer token. /v1/status returns the project and environment the key belongs to.

terminal
curl "$RIB_API/v1/status" \
  -H "Authorization: Bearer $RIB_KEY"

# {"ok": true, "environment": "test",
#  "project": {"name": "My game"}}
03 · Build

Read games and rankings

GET /v1/games lists the games available for paid matches. GET /v1/leaderboard returns the verified ranking (period=week|all, limit up to 20). Limit: 120 requests per minute per key. Match creation and settlement endpoints, and a typed SDK, are coming next.

server.js
const { RIB_API, RIB_KEY } = process.env;
const res = await fetch(
  `${RIB_API}/v1/leaderboard?period=week`,
  { headers: { Authorization: `Bearer ${RIB_KEY}` } }
);
const { data } = await res.json();
