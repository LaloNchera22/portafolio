Quickstart

From zero to your first API call in three steps.

01 · Key

Issue a test key

Create an account, open the console, go to Dev › API keys and issue a test key. You'll see it in full once; store it as a server secret, never in a browser or app bundle.

.env
RIB_KEY=rib_test_…
RIB_API=https://<project>.supabase.co\
/functions/v1/api
02 · Call

Check your key

Every request sends the key as a bearer token. /v1/status returns the project and environment the key belongs to.

terminal
curl "$RIB_API/v1/status" \
  -H "Authorization: Bearer $RIB_KEY"

# {"ok": true, "environment": "test",
#  "project": {"name": "My game"}}
03 · Build

Read games and rankings

GET /v1/games lists the games available for paid matches. GET /v1/leaderboard returns the verified ranking (period=week|all, limit from 1 to 100, 20 by default). Each key can make 120 requests per minute.

server.js
const { RIB_API, RIB_KEY } = process.env;
const res = await fetch(
  `${RIB_API}/v1/leaderboard?period=week`,
  { headers: { Authorization: `Bearer ${RIB_KEY}` } }
);
const { data } = await res.json();

Available today

What you can use right now.

REST API

/v1/status, /v1/games and /v1/leaderboard over HTTPS, server to server, at 120 requests per minute per key.

Projects and keys

Group keys by project, issue and revoke them in the console, and see when each key was last used. Keys are stored only as a hash.

Test mode

Everything runs on simulated rcoin, so you can try the full player flow in the console before any real money is involved. Live keys unlock at launch.
