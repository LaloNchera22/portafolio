Appeals

Hosted tournaments whose payout is on hold. Uphold pays the result as the host decided. Overturn pays the player you pick, forfeits the host commission to them and gives the host a strike. Refund all returns every entry fee and gives the host a strike.

Hosted matches past the decision window

Live hosted matches the host hasn't decided within 60 minutes. Open the room, read the chat and the end screens, and decide it if the host doesn't.

Match disputes

Oldest first. Read both reports, the room chat and the end screens (with their automatic check), then award the match to one player (the bracket advances) or void it (both are out). A rejected dispute's deposit goes to the other player.
