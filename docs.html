Runinback.createMatch()

Creates a new smart escrow session and pairs wallets together for a single game instance.

const match = await Runinback.createMatch({
  players: ['wallet_id_1', 'wallet_id_2'],
  wager: { amount: 10, currency: 'USDC' },
  oracleId: 'halo_infinite_1v1_slayer'
});

Parameters

players: Array of strings. The connected wallet addresses for the participants.

wager: Object containing amount (number) and currency (string).

oracleId: String. The ID identifying which game API to poll for the match result.
