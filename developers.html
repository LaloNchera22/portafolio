Quickstart

From zero to a wagered match in three steps.

01 · Install

Add the SDK

One package for the client and server. TypeScript types included.

terminal
# npm
npm install @runinback/sdk

# or pnpm
pnpm add @runinback/sdk
02 · Configure

Initialize the client

Authenticate with your sandbox key. Point at sandbox until you're ready for production.

client.ts
import { Runinback } from '@runinback/sdk';

const rib = new Runinback({
  apiKey: process.env.RIB_KEY,
  network: 'sandbox'
});
03 · Ship

Create, start, settle

Three calls cover the whole lifecycle. The oracle pays the winner automatically.

match.ts
const match = await rib.createMatch({
  players: [p1, p2],
  wager: { amount: 1, currency: 'SOL' }
});

await match.start();
await match.settle({ winner: p1 });
